# Редактор резюме

Учебный frontend-проект: редактирование резюме непосредственно на странице, сохранение изменений в браузере и скачивание PDF.

**Стек:** JavaScript, HTML, CSS, Vite. Экспорт — html2canvas и jsPDF.

## Возможности

- Редактирование текстовых блоков двойным щелчком.
- Сохранение изменений в `localStorage` после завершения ввода.
- Редактирование списков, тегов и интересов.
- Сброс сохранённых значений.
- Экспорт текущего содержимого резюме в PDF.

## Запуск

Нужны Node.js и npm, совместимые с Vite 5.

```bash
git clone https://github.com/qcvnnn/frontend-resume.git
cd frontend-resume
npm ci
npm run dev
```

Для сборки и локального просмотра:

```bash
npm run build
npm run preview
```

## Использование

Дважды нажмите на редактируемый текст. Введите новое значение и нажмите Enter или завершите ввод кликом вне поля. Кнопка скачивания создаёт `resume.pdf`; кнопка сброса возвращает исходные данные.

## Структура

- [index.html](index.html) — разметка резюме.
- [js/main.js](js/main.js) — редактирование и сохранение.
- [js/pdfDownloader.js](js/pdfDownloader.js) — формирование PDF.

- [css](css) — оформление и анимации.

## Ограничения

Данные сохраняются в текущем браузере без серверной синхронизации. PDF формируется из изображения страницы, поэтому текст в нём не становится отдельными редактируемыми текстовыми блоками. Сторонние библиотеки и изображения должны загрузиться до экспорта.

Проект выполнен по учебному заданию на разработку frontend-интерфейса.
